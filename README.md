# Anim Katwal — Portfolio

A responsive, single-page personal portfolio built with plain HTML, CSS, and JavaScript. No build tools or external libraries required.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/ (root)**, then press **Save**.
4. Wait for GitHub Pages to publish the site. The live URL will appear on the Pages settings screen.

## Personalize it
Edit `index.html` to update the introduction, project details, skills, and links. Add project demo URLs and screenshots when they are ready.

## Built with
- HTML
- CSS (responsive layout)
- Vanilla JavaScript
